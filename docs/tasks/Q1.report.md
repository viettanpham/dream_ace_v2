## Step 0 Facts (Pre-change Audit)
- **Queue component**: `TurnQueueBar` (`src/components/TurnQueueBar.tsx`, `variant="sidebar"`), mounted in `BattleScreen.tsx` (`~2468–2476`).
- **Pre-change row counts & deciders**: `Mở rộng` (`expanded`) passed `maxUpcoming={4}` (`4` rows max); `Dòng` (`line`) passed `maxUpcoming={10}` + `fillHeight={true}` (`10` rows max); shrunk dynamically as living units dropped and disappeared when `visibleUpcoming.length === 0`.
- **Pre-change name classes & truncation**: Acting row sliced both names via `formatShortUnitName(..., 10)` inside a single `whitespace-nowrap truncate` span without `min-w-0`/`flex-1`; queue rows rendered `{item.shortName}` (`formatShortUnitName(..., 10)`) with `whitespace-nowrap truncate` and no `min-w-0`.

## Changes Implemented
1. **Fixed 5-row scrollable list (`QUEUE_VISIBLE_ROWS = 5`)**:
   - Exported `QUEUE_VISIBLE_ROWS = 5`, `TURN_QUEUE_UPCOMING_MAX = QUEUE_VISIBLE_ROWS`, `TURN_QUEUE_ACTING_NAME_MIN_PX = 56`, `TURN_QUEUE_SIDEBAR_HEIGHTS`, and pure height helpers in `src/utils/battleDisplay.ts`.
   - `fixedRowCount = Math.min(5, unitsAtStart - 1)` is captured once at battle start (`unitsAtStart` + `battleInitMetaRef`) and never shrinks when units are destroyed; independent of `Dòng` / `Mở rộng` log modes (`maxUpcoming` & `fillHeight` props removed from `BattleScreen.tsx`).
   - Upcoming container (`turn-queue-upcoming-list`) has fixed height `rows × 26 + (rows - 1) × 4` (`146px` for 5 rows) with `overflow-y-auto overflow-x-hidden tactical-scroll tactical-scroll-thin`; when fewer turns remain, blank space stays with no placeholders and `+N` overflow chip continues to reflect `allUpcoming.length - fixedRowCount`.
2. **Full names & flex truncation**:
   - Acting row (`[side tag] Attacker > Target`) and every sidebar queue row render full `entry.name` / `targetName` (no 10-char slicing).
   - Name elements use flex `min-w-0 truncate` with zero `max-w-*` limits, full names in `title` attributes, and acting-row width sharing (`minWidth: min(56px, 42%)` when long & both attacker and target exist).
3. **Constant queue height across turns & battle end**:
   - Round header locked at `32px`, acting row locked at `36px` (rendering `turn-queue-acting-empty` with localized `queue.battleEnded` / `queue.noActiveActor` when there is no actor or at battle end), and container height locked to `260px` (`>= 6` starting units) across the entire battle.
